## [0.4.0](https://github.com/OpenRAL/openral/compare/v0.3.1...v0.4.0) (2026-09-06)


### ⚠ BREAKING CHANGES

* **safety:** check panda_link5 / panda_link7 at hull fidelity instead of exempting it ([#202](https://github.com/OpenRAL/openral/issues/202))
* **nav:** the `payload_footprint` launch arg is renamed `payload_scan_filter` and no longer starts a footprint publisher; `openral_nav2_bringup.payload_footprint_node` is removed. Nav2's footprint is now the manifest's bare chassis, substituted statically at launch by `RobotDescription.nav2_param_overrides()`.
* **safety:** `CollisionHit` gains `advisory`, and a payload contact inside a live place declaration within `place_advisory_depth` of the allowance no longer latches or asserts E-stop. Set `place_advisory_max_consecutive: 0` to restore the previous behaviour exactly.
* **collision:** publish the world grid on the map's own lattice, not the base frame's
* **sim:** the two `test_depth_camera_synth.py` tests asserting that a visual-only countertop must be the reported surface are inverted deliberately. Their scene is kept because it is the adversarial one — the slab is built to fall outside its body's collision BVH — but its physical surface is the carcass at 0.890; 0.920 is paint, and an arm passes through it.
* **msgs:** return candidate masks from SegmentInView, select on geometry in the HAL

### ⚠ BREAKING CHANGES

* **reasoner:** the deprecated `OPENRAL_REASONER_LLM_*` provider-first env contract is removed (ADR-0088; deprecated in 0.2.0 as a one-release shim). An environment that sets only those variables now fails with "`OPENRAL_REASONER_MODEL` is unset" instead of silently selecting a model — deliberate, so a reasoner driving real hardware refuses to start on stale configuration rather than picking something unintended. Every provider the old contract reached is expressible model-first via `OPENRAL_REASONER_ENDPOINT`, which accepts the named endpoints `anthropic` / `openrouter` / `gemini` / `xai` / `deepseek` / `huggingface` / `ollama` / `vllm`. Migration table: [`packages/openral_reasoner_ros/README.md`](https://github.com/OpenRAL/openral/blob/master/packages/openral_reasoner_ros/README.md).
